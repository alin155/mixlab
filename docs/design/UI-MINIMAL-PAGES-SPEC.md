# Cutter 全页面极简风格实施规格（已确认方向）

> 确认日期：2026-10-30  
> 设计基线：docs/design/mockups/minimal-*.html + minimal-all-pages-contact.png  
> 用户结论：整体方向确认，按极简工作台统一所有剪辑端页面。

## 设计原则

- 统一 AppShell：顶栏 + 左侧栏 + 页面标题区；
- 每页只有一个 primary 操作；
- 少卡片、多分隔线；列表/表格/Inspector 密度统一；
- 工作区临时残留只保留左侧栏入口，不再出现顶栏横幅；
- 不改变 API、业务规则、项目数据模型。

## 实施批次

### Batch A：素材搜索 + 剪切任务

- 素材搜索：候选/文案/Inspector 三栏，轻卡片，悬浮剪切按钮定位正确；
- 剪切任务：摘要行替代 KPI 卡片；表格占主区，任务详情固定右栏；队列 ETA 保留；
- 保留现有搜索、选区、剪切、重试、打开目录功能。

### Batch B：本地素材 + 公共素材库 + 素材详情

- 本地素材：网格 + 右侧 Inspector，缩略图加载占位；
- 公共素材库：网格 + 右侧预览/信息；
- 素材详情：视频 + 文案主区，右侧选区/任务；
- 保留播放、打开目录、加入待剪、剪切功能。

### Batch C：缓存管理 + 设置

- 缓存管理：摘要行 + 分类清单 + 清理操作，去掉 6 个独立 KPI 卡；
- 设置：4 个分组 + 右侧环境检查，去掉超长表格；
- 保留清理、保存、诊断等现有功能。

## 每批交付

- 独立分支（从当前 main）；
- typecheck + 产品测试；
- Windows 安装版 1536×1024 / 1440×900 截图；
- 保留空态/加载态/错误态；
- 不升版本/不发布，Mac 审查后再合并发布。

## 暂不包含

- 全站 A+B 项目作用域语义（另行排期）；
- 极速溢出模式；
- API/协议/数据模型变更。
