# MixLab Cutter 剪辑端 UI/UX 审计与重排建议

> 版本：0.18.13 现状（1536×1024 截图）  
> 目的：先统一方向，再按页面迁移；本文件只做审计/方案，不改产品代码，不打扰 Windows 当前开发。  
> Mockup：workbench.html · cut-tasks.html · local-library.html  
> 截图：mockups/screenshots/（1536×1024、1440×900）

## 1. 结论摘要

当前界面不是"配色不好"，而是缺少统一的页面壳层与信息层级：每个页面自行组织标题、筛选、卡片和详情，导致：

- 页面没有统一标题/上下文，用户进入页面后不知道"当前对象/下一步"；
- 左栏底部状态卡与页面内信息重复；
- 右栏/详情区宽度不足，表格和长标题被截断；
- 筛选、卡片、按钮、状态标签风格不一致；
- 空态/错误态/加载态没有统一模板；
- 信息密度忽高忽低（缓存页很挤、任务页大面积空白）。

建议路线：先统一设计令牌 + AppShell + 基础组件，再重排核心页面；不做一次性大改。

## 2. 跨页面问题（按优先级）

| 优先级 | 问题 | 影响 | 建议 |
|---|---|---|---|
| P0 | 无统一 AppShell：页面标题/面包屑/操作区位置不一致 | 用户迷路，页面观感碎片化 | 统一：侧栏 + 顶栏（面包屑/标题/操作） + 内容区 |
| P0 | 侧栏底部项目/素材库/任务/服务卡与页面内容重复 | 信息噪音、底部拥挤 | 侧栏只保留项目与账号摘要；系统状态在顶栏或设置页 |
| P0 | 右栏/详情区过窄，表格被挤压换行 | 任务标题/时间/状态不可读 | 表格占主区，详情固定右栏或抽屉；列宽/截断规则固定 |
| P1 | 筛选器无统一容器/标签 | 多个按钮与标题抢视觉 | 统一 FilterBar：作用域 + 状态 + 排序 + 右侧主操作 |
| P1 | 按钮层级不清（主/次/文字/危险混用） | 用户不知道主操作 | 每个区域最多一个 primary；危险操作红色；其余 secondary/ghost |
| P1 | 空态/错误/加载样式不统一 | 页面看起来"坏了一半" | 统一 EmptyState / ErrorState / Skeleton |
| P1 | 中文长标题/路径无溢出策略 | 换行/截断混乱 | 标题 1~2 行截断；路径等宽字体 + tooltip |
| P2 | 间距/字号/圆角/阴影不统一 | 拼装感 | 设计令牌：4/8/12/16/24、字号 11/12/13/14/16/24 |
| P2 | 状态标签颜色语义不一致 | 误读 | 统一 Badge：等待/执行/成功/失败/信息 |
| P2 | 1536 和 125%/150% 缩放适配未验证 | 布局错位 | 响应式断点 1280/1100；截图基线 |

## 3. 逐页审计

### 3.1 素材搜索 / 工作台（material-locator）

现状：左栏导航、中间"候选素材 + 视频文案"、右栏"视频 + 选区 + 最近任务"；页面没有 H1；搜索框独占一行；右栏三块内容堆叠，最近任务表格被压缩。

问题：
1. 顶部无页面标题/说明，搜索框缺少作用域与筛选上下文；
2. "候选素材"与"视频文案"标题同级，主次不清；
3. 右栏视频巨大，选区信息/任务被挤到最下方；
4. 任务表在 320px 列内换行严重；
5. 候选卡片标题/元信息/命中数对齐不稳定；
6. 右侧"打开文件目录/剪切"等按钮主次不明确。

重排方案（见 mockups/workbench.html）：
- 页面标题「素材搜索」+ 一句说明 + 全局搜索/筛选行；
- 三栏：候选 330px / 文案 fluid / Inspector 350px；
- Inspector 改 Tabs：视频 / 选区 / 任务，避免堆叠；
- 候选行固定缩略图 64×40 + 两行标题 + 元数据 + 命中 badge；
- 任务概览只在 Inspector 的"任务"Tab，完整列表去剪切任务页；
- 主操作：剪切这段（primary）；加入待剪清单（secondary）；打开目录（ghost/secondary）。

### 3.2 剪切任务（cut-tasks）

现状：标题/副标题、统计卡、流水线卡、表格、右详情；表格列宽不足，来源/选中文案被截断；右栏详情窄；表格下方大面积空白。

问题：
1. 缺少"队列位置/预计等待"，用户以为卡死；
2. 当前项目过滤不显眼，容易看到 0 条；
3. 表格承载过多列，标题和操作挤在一起；
4. 详情固定右栏但没有层级（关键错误/输出路径/下一步操作）；
5. 已完成任务与失败任务缺少明确下一步。

重排方案（见 mockups/cut-tasks.html）：
- 页面头部：标题 + "串行执行"说明 + 打开目录/刷新；
- KPI 四卡：等待 / 剪切中 / 已完成 / 失败；
- 流水线 banner：当前任务 + 百分比 + ETA；
- FilterBar：状态 + 项目（显式显示"当前项目/全部项目"）+ 右侧操作；
- 表格列：状态 / 来源 / 时间段 / 模式 / 进度-ETA / 耗时 / 操作；
- 详情卡：状态/模式/选区/剩余时间/溢出/输出路径 + 打开任务目录 / 改精剪 / 重新剪切。

### 3.3 本地素材（local-library）

现状：空态时整页大面积空白；筛选按钮与标题同一行抢视觉；右侧详情空；有素材时未形成稳定的网格/详情结构。

问题：
1. 空态没有明确下一步（切换项目/全部素材）；
2. 筛选器没有分组/标签；
3. 详情与列表没有稳定的选中态；
4. 播放器/元数据/操作缺少统一 Inspector。

重排方案（见 mockups/local-library.html）：
- 页面标题 + 说明 + 打开目录/新建；
- FilterBar：当前项目/全部素材 + 全部/横屏/竖屏；
- 网格卡片：缩略图 + 时长 + 标题 + 来源/项目 + 创建时间；
- 右侧 Inspector：视频/元数据/操作/选中文案；
- 空态：说明 + 切换全部素材 + 新建项目。

### 3.4 缓存管理（cache-management）

现状：5 个指标卡 + 孤立第 6 卡；下方两列卡片高度不一致；路径/长文本拥挤；右侧缓存路径列表信息密度高。

问题：指标卡无分组、无优先级；空间指标与路径信息混在一起；清除按钮/保护项说明不清晰。
建议：分组为"概览 KPI / 清理操作 / 明细（路径、索引、缓存）"；KPI 最多 4 个；路径用等宽字体 + 折叠；清理操作需要 preview 和 protected 列表。

### 3.5 设置（settings）

现状：长 key-value 表格 14+ 行，右侧空白；环境检查孤立。
建议：分组卡片（服务状态 / 素材与工作区 / 剪切默认 / 账号与安全 / 诊断）；每组 3~6 行；右侧放"环境检查摘要/快捷入口"；长路径省略 + tooltip。

### 3.6 其他页面

- 公共素材库 / 素材详情：与本地素材共用"网格 + Inspector"模板；
- 项目首页：使用统一 PageHeader + 项目卡/最近项目模板；
- 首次运行页：统一表单 token 与步骤条。

## 5. 页面模板规范

1. AppShell：侧栏 232px（窄屏 64px）+ 顶栏 64px + 内容区 24px padding；顶栏包含面包屑、页面标题/操作；
2. PageHeader：eyebrow + H1 + 一行说明 + 右侧主操作；
3. FilterBar：状态分段 + 作用域/项目 + 排序 + 右侧工具；
4. List/Table：固定列宽策略、标题 1 行截断 + tooltip、状态 badge、操作列靠右；
5. Inspector：Tabs 或分段；最多 3 个 tab；操作区固定在底部；
6. Empty/Error/Loading：统一文案与主操作；骨架屏用于列表/详情；
7. 响应式：≥1440 三栏；1100~1280 收窄侧栏/右栏；<1100 侧栏图标化、Inspector 下移；验证 125%/150% 缩放。

## 6. 实施路线

| 阶段 | 内容 | 时间估算 |
|---|---|---|
| Phase 0 | 设计令牌 + AppShell + 基础组件（Button/Card/Badge/Table/Empty/Skeleton）+ 截图基线 | 3~5 天 |
| Phase 1 | 素材搜索、剪切任务两个核心页重排 | 3~5 天 |
| Phase 2 | 本地素材、缓存管理、设置 | 3~5 天 |
| Phase 3 | 深色主题、快捷键、可访问性/缩放、视觉回归 | 按需 |

不采用"一次性大改"：每页迁移 + 截图 diff + 可回滚；功能开发（0.18.13.1/0.18.14）与 UI 改版分分支进行，避免冲突。

## 7. 验收标准

- 1440×900 / 1536×1024 / 1920×1080 无横向滚动、无关键内容截断；
- 每个页面一个 primary 操作；状态 badge 语义一致；
- 表格标题最多 1 行截断 + tooltip；关键数字可读；
- 空态/错误态有明确下一步；
- 125%/150% 缩放下不重叠；
- Playwright 截图基线对比，允许的视觉 diff 明确；
- 2~3 位真实剪辑师完成核心路径（搜索→选区→剪切→本地素材）。

## 8. 风险与不做的事

- 不做纯视觉换皮：必须先统一 IA/模板，否则越改越乱；
- 不在功能热修分支里混入 UI 重构；
- 不引入重型 UI 框架/外部 CDN；沿用现有 React + UI Foundation 基础；
- 不一次性替换所有页面，按核心路径优先。
