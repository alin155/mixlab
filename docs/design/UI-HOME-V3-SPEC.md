# UI 首页 v3（极简工作台）实施规格

> 用户选择：方案 A（极简工作台）  
> 基线：main 4594991（0.18.16，UI Phase 0）  
> 实施方：Windows；Mac 负责设计审查/发布  
> 分支：ui/home-v3-minimal（从 main 新建）

## 1. 目标

把首页从"Hero + 卡片拼盘"改为安静的工作台：命令栏 + 最近项目 + 最近任务；同时解决工作区残留提示条无法关闭的问题。

## 2. 本轮范围（必须做）

1. **首页结构**
   - 页面标题：工作台 + 一行说明；
   - 右侧只保留一个 primary「新建项目」，可保留 secondary「打开待剪清单」；
   - 顶部命令栏：搜索输入 + 范围选择 + 搜索按钮；右侧显示本地/公共素材数量；
   - 「最近项目」：4 张紧凑项目卡（16:9；标题、已剪/待剪/时间）；当前项目高亮；
   - 「最近剪切」：一张紧凑表格（状态/来源/时长/完成时间，最多 5 条，全部任务链接）；
   - **删除**现有 Hero、快速开始卡片；不要重复导航已有入口。

2. **项目卡交互**
   - 点击卡片进入项目；
   - 原「打开目录/重命名/删除」不能丢：收进卡片右上角「⋯」菜单或选中态操作；
   - 不在每张卡上常驻重复按钮。

3. **工作区残留提示条**
   - 单行紧凑样式，带「关闭 ×」；
   - 点击关闭后写 localStorage（建议 key 含 residue count；关闭后同 count 不再显示，count 变化或 24h 后重新提示）；
   - 保留「去清理」链接；
   - 关闭不删除任何文件；0 残留时自动隐藏。

4. **保留**
   - 顶栏项目切换器、全局壳层、通知栈；
   - 搜索/项目/剪切的业务规则不变；
   - 现有路由和入口可用。

5. **验证**
   - typecheck、产品测试；
   - Windows 安装版 1536×1024 / 1440×900 首页截图；
   - 无横向滚动；1536 尽量无纵向溢出；
   - 点击项目卡可进入；⋯ 菜单动作可用；
   - 提示条可关闭、刷新后保持关闭、count 变化重新出现；
   - 搜索命令栏可跳素材搜索。

## 3. 不做

- 素材搜索/剪切任务/本地素材内容重排（Phase 1）；
- 全站项目作用域 A+B（Phase 1）；
- 悬浮剪切定位修复（Phase 1）；
- 极速模式、API/业务规则改动；
- 不升版本/不发布，等 Mac 审查。

## 4. 交付

- 分支/commit、改动文件；
- typecheck/测试；
- 1536/1440 首页、项目卡菜单、提示条关闭前后截图；
- 与 docs/design/mockups/home-v3-minimal.html 的差异说明；
- 不要直接改版本/发布。
