# 统一智能剪辑端实施与验收记录

日期：2026-10-07。实现基于已确认的统一原型；独立工作树和分支 `codex/unified-cutter-20261007`，基线 `f525c0e`。预览：<http://127.0.0.1:5198/#/retrieve>，本机 API 3793。

## 已实现

- 创作：原剪辑端真实素材检索、句内/跨句/反向鼠标拖选、直接剪切、时间微调、复剪、片段列表与顺序调整；分别导出或合并完整视频。
- Pro 文案成片：整段文案输入、自动命名、手动/自动来源区分、原声匹配审核、人工拖选补句、人物构图与字幕、真实本地 MP4/SRT/来源记录。
- 工作区：基础及智能项目、真实剪切/合并/智能任务，失败重试、暂停/继续、取消，本地成果播放和目录入口。
- 素材：管理端已发布公共库、已有转写与索引；本机剪切素材可播放、改名、管理和复剪。抖音下载只供参考文案，不进入素材库。
- 缓存与文件保护：未完成的合并禁止删除项目记录或输入文件；目录调整与缓存清理互斥。真实磁盘占用和分类清理；禁止删除素材库、本地产出、活动任务、检查点或越界/符号链接目标。
- 账号：沿用管理端审核、密码、设备、会话。账号默认普通；管理端增加普通/Pro 级别；授权存入独立兼容文件，旧账号结构不变。界面、HTTP API 与后台任务同时检查权限。
- Windows：候选应用独立标识、安装目录与默认工作区；关闭窗口隐藏至托盘；托盘明确退出先请求引擎保存检查点，再停止进程树。实现依据官方 [Tauri 托盘 API](https://v2.tauri.app/learn/system-tray/)。

## 当前验证证据

- 类型检查、智能端 Web 构建、管理端 Web 构建、本机引擎打包、macOS Rust 编译检查通过。
- 智能模块 14/14 测试通过，包括真实 FFmpeg 成片/字幕、模型推理、审核/取景、恢复、监控/转写接口桩、权限、真实剪切/复剪/合并和受保护清理。
- 管理端/Cutter API 最终扩大回归 650 项：648 通过，2 失败。两项均为旧 Cutter 本地素材统计时序断言；在未改动的 `f525c0e` 基线上，同样两项断言均可复现失败。新版本未修改该统计逻辑，未把既有失败记作通过。
- 管理端真实 API 浏览器验收完成测试账号普通/Pro 切换，并验证剪辑端智能入口随权限更新。新增级别接口响应格式与非法级别回归测试通过；临时管理端服务验收后已停止。
- 浏览器真实交互验证普通/Pro 登录、跨句与反向拖选、真实剪切、本地素材注册播放、Pro 匹配/成片/字幕与来源、拖选补句返回原作品、两段清单导出并合并、真实缓存保护；1180×720 CSS 布局无横向溢出。截图保存本目录。
