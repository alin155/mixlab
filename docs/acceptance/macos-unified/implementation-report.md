## 实施方案

执行 [Mac 优先实施方案](../../architecture/unified-cutter-macos-first-plan.md)：同一 Web UI 与业务引擎，分别封装 Mac 和 Windows 运行时。管理端统一发布素材、审核账号和设置普通/Pro；客户端保留成熟检索剪切并在 Pro 下增加智能能力。媒体、缓存、项目与成果在本机处理，监控下载仅供参考文案。

顺序为环境/素材、账号、真实媒体闭环、Mac 桌面与恢复、受控自动创作、Windows 平台复验。Windows 正式实机复验和向现有用户升级仍不启动；已有 Windows 构建证据保留，但不能代替新的 Mac/Windows 全功能验收。

## 本批次完成

- 增加 Apple Silicon Mac 候选 `.app` 构建。内置 Node 24.21.0、可移动 Python 3.12.14、FFmpeg、原生 FFprobe 6.1.6、模型和字体；资源不再链接其他开发工作树。Mac 最低版本 14.0，与 NumPy wheel 的最低平台一致。Mac 工作区在创建目录前检查挂载及实际路径，拒绝 SMB/NFS/AFP/WebDAV 网络卷宗。
- 包内引擎按平台选择可执行文件。显式包内 FFprobe 路径优先，不允许 Homebrew 自动替代包内路径掩盖资源问题。FFprobe 从校验 SHA-256 的官方源码编译为 ARM64，链接只依赖系统库/框架。
- 修复本机候选资源签名封装，采用本机临时签名并通过严格完整性检查；这是本机验收包，尚未公证或作为正式分发签名包。
- 设置增加登录前公共库连接检查，显示保存的根目录、发布版本、数量或真实错误；公共素材页显示当前路径。检查在 10 秒后返回超时，重复检查复用未完成读取，避免连续堆积同一阻塞打开。
- Unix 桌面退出先请求引擎保存检查点，限时等待后终止本应用进程组；不再无期限等待被网络卷宗打开操作阻塞的子进程。Windows 原退出路径保留。
- 管理端与客户端以密码认证模式执行真实 HTTP 联调：未登录管理员不能审核；注册/待审/批准/登录、普通/Pro 升降级、重置密码与会话撤销、禁用均验证。
