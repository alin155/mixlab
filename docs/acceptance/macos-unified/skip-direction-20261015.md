## 缺句可明确跳过

成片调整页在未匹配提示旁提供“跳过未匹配的 N 句”；审核页每句提供“跳过此句 / 恢复此句”。跳过为独立、可恢复的决定，保留原目标文案、匹配结果与候选，不把缺句伪装成匹配成功。批量跳过仅作用于缺句和待检索项，不代替近似原声确认或事实冲突处理；其他句子也可以在审核中单独选择跳过。

导出只处理未跳过且已通过审核的片段。跳过句不进入画面、声音、字幕或实际原声文本，其余片段按原顺序连续拼接，字幕时间轴同步重排。来源记录保留原始输入，单独列出跳过句与原编号。至少保留一句可用原声；全部跳过时不生成空视频。恢复后沿用原审核状态，需要补选的句子重新进入待处理。重新匹配会产生新的方案，重新进行跳过选择。

API 校验作品版本、Pro 权限及匹配/导出忙状态；单句选择新候选、拖选补句会恢复该句。批量接受、待处理计数、预计时长、预览时间线及实际渲染均排除跳过项；保留片段继续执行老师身份检查。旧数据没有跳过字段时保持原行为。
