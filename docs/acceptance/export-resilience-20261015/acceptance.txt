已实现
1. 统计写入职责
公共 Cutter API 默认追加 usage-events/events.ndjson，显式关闭 summary projection 的 write-through 与失效删除；智能端适配器沿用相同限制。客户端不打开管理端统计 SQLite 做写操作。
管理端仍可依据事件文件签名发现新事件、重新汇总。没有更改事件格式、账号/权限模式、公共库发布格式。
注意：这是停止客户端修改统计 SQLite，不是禁止所有 NAS 写入；既有事件追加及账号流程仍存在。旧客户端在升级前仍保持旧行为。

2. 短暂断线
只对 EBADF、ESTALE、ENOTCONN、网络重置/不可达/超时等连接类错误重试。
等待 2、5、10 秒，最多重试 3 次（加上初次共 4 次）。这些是重试间隔，不是每次操作的总 I/O 超时。
普通剪切队列在源解析、预检、剪切阶段重试同一任务，并在原阶段显示重试次数。直接剪切调用同样具备连接重试。
智能导出对源复制和账号连接检查作限次重试。账号显式失效或 Pro 权限撤销仍暂停，不把权限失败当作网络失败。
源文件变更、内容校验不符、权限/空间不足等永久错误不盲目循环。

3. 已完成内容保护
普通队列只重试未完成片段，已完成的其他任务和成果保留。
智能任务先验证完成片段的音视频轨、分辨率、时长和 SHA-256，再复用；不会先去打开该片段的 NAS 原视频。
旧任务没有 checksum 时，先 ffprobe 检查再补记录，以兼容用户现有的完成片段。损坏片段单独重建。
源复制使用 .partial，失败清理；成功还需核对长度、源指纹和已发布内容 hash。半成品不能冒充缓存。
保留粒度为已完成片段，不是复制到一半的字节偏移；中断的当前原文件需重新复制。重试耗尽保留任务，连接恢复后可点击重试/继续；不会无限重试。
字幕与来源清单从锁定本机快照重新构建。工作版本变更时清除旧完成标记和校验，防止错误复用。

4. Windows 检查发现并修复的兼容问题
缓存身份比较规范化路径分隔符，避免同一源视频因 / 与反斜线不同而错失本机缓存。
Windows rename 已存在目录会返回 EPERM；仅确认目标为目录时进入既有快照验证/隔离修复流程。
语义测试选择对应平台的 Python；路径断言比较规范化路径，没有放宽媒体/权限/统计等业务断言。

无干扰上线顺序
1. 在隔离状态验收候选包；先验证一台空闲电脑，保留旧安装包。
2. 等该电脑无运行中的剪切、导出和自动监控，明确退出后备份本机状态/工作区，再切换候选。
3. 验证登录、真实素材检索、选文剪切、原声成片与已有任务恢复，再逐台升级；不强制踢出其他用户，不重启 NAS。
4. 不同时让两个应用实例使用同一个状态/工作区。
5. 如有回归，明确退出候选，恢复旧包；必要时恢复升级前备份。不要删除已完成成果，不回滚/修改 NAS 公共库。
