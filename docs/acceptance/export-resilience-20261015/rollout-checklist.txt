本批候选不会自动安装、更新或重启当前用户应用。

验收电脑每次只启动一个同应用 ID 的实例；不要直接双击候选并与当前实例并行。
1. 等待当前剪切/导出/监控空闲；记录现用版本，明确退出。
2. 复制本机应用状态及工作区备份，保留旧包；不要修改 NAS 发布内容。
3. 先切换一台 Mac：登录、读取当前公共库、文案检索鼠标选词剪切、历史已完成片段保留、智能原声/字幕成片、退出与重新打开后恢复。
4. 原有失败智能任务在连接恢复后点“重试”；不改文案版本即可尝试复用已完成片段。当前未完成源文件复制会从头读取。
5. 观察候选日志及结果，随后一台空闲 Windows 做同等实机验收，再逐台升级其他设备。
6. 回归时退出候选、切回旧包；必要时恢复该机备份。旧客户端仍有旧统计写入行为，回滚后也应记录此限制。
