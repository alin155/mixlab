# 统一剪辑端落地计划

基线：`f525c0e`；分支：`codex/unified-cutter-20261007`。产品依据：用户确认的 `http://127.0.0.1:5196/#/retrieve` 原型。

## 范围与实施顺序

1. 接入原剪辑端真实检索、文案拖选、剪切队列、复剪、本地素材、项目及文件管理。复用已验证的 cutter API / cutter-local / FFmpeg，统一客户端只提供一个本机引擎入口。
2. 复用管理端剪辑师注册、审核、密码、设备和会话体系。普通账号默认仅基础功能，Pro 权限同时由界面与服务端校验；新增授权文件兼容旧账号存储。
3. 保留智能端手动/自动文案成片、原声审核、人物取景、字幕和抖音监控。监控视频仅作参考文案；人工补选回到原作品。
4. 素材导航为本地素材、公共素材库、缓存管理；设置与账户在底部。真实缓存统计与清理保护作品、产出、活动任务及检查点。
5. Windows 窗口关闭隐藏到托盘，明确退出通知引擎保存检查点并停止进程。

## 验收

- 真实已发布测试素材：句内、跨句、反向选择；直接剪切、复剪、队列、本地播放与来源。
- 共享账号：未登录拒绝访问，普通账号不能直接调用智能 API，Pro 降级后后台停止智能执行；旧账号仍可登录。
- 手动与自动作品独立来源标识；不确定/缺失匹配保留审核；原声输出含 MP4、字幕及来源记录。
- 缓存清理前后：本地素材、项目、成片内容及 hash 不变；路径越界/符号链接不清理。
- Web 真实 API 浏览器验收；构建、类型检查、契约和回归测试；Windows 特有行为单独记录验收状态。

## 发布与回滚

开发代码、预览端口、测试账号、工作区均隔离。现有管理端、剪辑端安装包及 NAS 数据不自动升级。发布前保留账号授权文件及本地数据库备份；旧版账号文件不增加必填字段。候选安装包验证通过后，再由用户决定上线与分批升级。
