## 本次修复

### 1. 盘符根工作区导致剪切任务永久等待

- 当“本地素材库地址”选择为盘符根目录（例如 `F:\`）时，Cutter 启动会执行 `mkdir(F:\\)` 并得到 `EPERM`，workspace 租约获取失败；
- 后果：剪切队列 drain 被跳过，任务一直停在“等待中”；
- 0.18.29 修复：
  - 已存在工作区不再重复 mkdir；
  - 盘符根写租约失败时自动降级到本机固定租约目录；
  - 租约仍不可用时，剪切任务页显示明确错误，不再静默 pending。

### 2. 修改本地素材库地址后仍导出到旧目录

- 0.18.28 设置页只保存配置，未重启本机引擎；用户继续剪切仍写旧目录（例如 C 盘）；
- 0.18.29 修复：
  - 保存后立即比较配置目录与引擎实际 `workspace_root_path`；
  - 不一致时显示“待应用”，明确显示配置目录与引擎当前目录；
  - 未应用前阻止新的剪切/导出；
  - 提供“立即应用（重启本机引擎）”，应用后确认引擎目录并刷新工作台；
  - 启动时也会检查，重启后仍不一致会继续提示。
