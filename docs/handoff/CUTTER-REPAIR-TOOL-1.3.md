# MixLab Cutter 修复工具 1.3：去掉多余按钮，自动诊断/自动上一版本回退

- 背景：1.2 仍把“只导出诊断包”“回退到 0.18.27”作为主界面按钮。诊断已经会自动提交专家介入，不需要用户手动导出；回退目标也不应硬编码 0.18.27。
- 目标：主界面只保留“一键修复”；其余动作自动化或收进“更多”。

## 1. 主界面收敛

默认窗口只保留：

- 状态行；
- 日志区；
- 一个主按钮：**一键修复**；
- 一个小按钮/链接：**更多**（高级菜单，普通剪辑师不需要）。

“只导出诊断包”“回退”不再作为主界面并列大按钮。

## 2. 诊断自动提交

- 一键修复失败时自动生成并提交专家介入请求；
- 不再要求用户点“只导出诊断包”；
- 高级菜单里保留“导出诊断包（备用）”，只给管理员/支持使用；
- 自动提交失败（NAS 不可写）时，才在失败结果中提示本地保存路径。

## 3. 回退目标动态化

不允许硬编码 0.18.27。

回退目标 = 当前版本之前、**最近一个可用且已验证的版本**：

- 读取当前 Cutter 文件版本；
- 优先查本机已下载的更新缓存：
  - `%LOCALAPPDATA%\MixLab Cutter\updates\`
- 再查 NAS 版本目录：
  - `\\192.168.1.27\MixLab\安装包\MixLab Cutter\<version>\`
- 选择小于当前版本的最高版本；
- 校验安装包存在，并尽量校验 SHA256SUMS；
- 例如当前 0.18.31 → 回退 0.18.30；当前 0.18.30 → 回退 0.18.29；
- 找不到上一版本时不显示回退按钮，直接提交专家介入。

## 4. 自动回退策略

自动回退只在**应用无法启动/加载**且修复失败时考虑：

1. 先完成安全修复尝试；
2. 仍失败 → 自动提交专家介入；
3. 如果满足：
   - 识别到上一版本安装包；
   - 安装包 SHA256 校验通过；
   - 当前没有正在执行的剪切任务；
   - 已知当前版本属于启动失败场景；
   则自动准备回退；
4. 回退执行：
   - 优先尝试安装器静默模式；
   - 若安装器必须交互，至少自动打开正确版本安装包，不再要求用户选版本；
   - 回退后仍提交诊断包；
5. 不满足条件则只升级专家，不自动降级。

安全边界：

- 不跨大版本自动回退；
- 不删除项目/素材；
- 不回退到未验证安装包；
- 有活跃剪切任务时不自动回退。

## 5. UI 细节

高级菜单内容：

- 导出诊断包（备用）
- 回退到上一版本：显示检测到的具体版本，如“回退到 0.18.30”
- 打开日志目录

主界面不再出现“0.18.27”字样。

## 6. 测试

1. 当前 0.18.31：检测上一版本 0.18.30，显示正确；
2. 当前 0.18.30：检测 0.18.29；
3. 上一版本安装包缺失：不显示回退，直接专家介入；
4. SHA256 不匹配：不回退，升级专家；
5. 修复失败自动提交，不要求点导出；
6. 高级菜单手动导出仍可用；
7. 正常修复成功不触发回退；
8. 自动回退只启动正确版本，不出现 0.18.27；
9. 0.18.32/下一版本真机验收。
