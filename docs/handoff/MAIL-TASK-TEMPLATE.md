# 任务下发模板（必须包含 watch_branch）

> 目的：避免远端 agent 回复“还在做”但实际不再产出。  
> 规则：代码类任务必须声明 `watch_branch`；没有该字段的任务不会被停滞 watchdog 监控。

## 模板

```
类型：task
目标：一句话说明本任务只做什么
watch_branch：ui/xxx（实际推送的功能分支）
验收标准：
- 具体命令/截图/文件
- 1536/1440 或其他明确尺寸
约束：
- 不改哪些范围
- 不升版本/不发布（如适用）
检查点：
- 接任务后 15 分钟内必须先 push 第一个 commit
- 之后每 10 分钟至少一次 commit 或明确 progress reply
- 超过 20 分钟无 commit = stall；超过 30 分钟 = Mac 可接管
阻塞时：必须回复“做到哪 / 卡在哪 / 下一步”，不能只回“还在做”
```

## 小任务拆分

- 一个任务最多 30 分钟；
- UI 类任务按“一个页面/一个 tab”拆分；
- 每个任务独立 commit + 截图/测试；
- 不把 8 个页面塞进同一个 task。

## 接管规则

- 20 分钟无新 commit：watchdog 告警；
- 30 分钟无新 commit：Mac 暂停 Windows 写权限并接管；
- 接管后 Windows 只负责本地测试包/截图/正式构建，不再改同一分支。
