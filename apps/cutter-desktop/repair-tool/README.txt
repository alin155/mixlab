MixLab Cutter 修复工具 v1.1.0

用途
- 升级 0.18.28 后如果一直停在“正在读取剪辑师工作台数据”，双击本工具，点一次“一键修复”。

使用
1. 双击“MixLab Cutter 修复工具.exe”。
2. 点“一键修复”，等待工具结束残留进程、重启 Cutter 并检查本机服务。
3. 成功时回到 MixLab Cutter 查看工作台。
4. 失败时工具会自动把诊断反馈提交给管理员，界面直接显示反馈编号（FB-...），无需你手动发送。
5. 如果 NAS/共享暂时不可用，诊断包会保存在本机队列，恢复后自动提交：
   %LOCALAPPDATA%\MixLab Cutter\repair\pending
6. “只导出诊断包”不修复，只生成桌面 zip 兜底。
7. “回退到 0.18.27”需二次确认，只打开 NAS 安装包，不静默降级。
8. 如果 Windows 提示“未知发布者”：点“更多信息”→“仍要运行”。工具为本机离线小工具，不需要联网。

自动提交
- 诊断包提交到 NAS 反馈收件箱：\\192.168.1.27\MixLab\CutterFeedback\inbox
- 启动时、每 5 分钟、网络恢复时自动重试；同一编号不会重复提交。
- 桌面 zip 只作为兜底，不再要求你手动发给管理员。

安全
- 不需要管理员权限。
- 不删除素材、项目或缓存。
- 不收集素材/项目/转写内容，不收集密码/token/Cookie；配置和日志中的敏感字段会脱敏。
- 不上传公网。
