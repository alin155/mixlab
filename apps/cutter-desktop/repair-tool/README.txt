MixLab Cutter 修复工具

用途
- 升级 0.18.28 后如果一直停在“正在读取剪辑师工作台数据”，双击本工具，点一次“一键修复”。

使用
1. 双击“MixLab Cutter 修复工具.exe”。
2. 点“一键修复”，等待工具结束残留进程、重启 Cutter 并检查本机服务。
3. 成功时回到 MixLab Cutter 查看工作台。
4. 失败时工具会把诊断包放到桌面，并尽量复制到 NAS：
   \\192.168.1.27\MixLab\CutterDiagnostics\<电脑名>\
   请把诊断包发给管理员。
5. “只导出诊断包”不修复，只收集日志和状态。
6. “回退到 0.18.27”需二次确认，只打开 NAS 安装包，不静默降级。

安全
- 不需要管理员权限。
- 不删除素材、项目或缓存。
- 不收集素材/项目/转写内容，不收集密码/token/Cookie；配置和日志中的敏感字段会脱敏。
- 不上传公网。
